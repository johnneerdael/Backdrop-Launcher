- Update Backdrop automatically. New releases are downloaded in the background, checked, and installed while Home is on screen, so an update never interrupts something you are watching.
- Add Install updates automatically under Settings → System. It is on by default.
- Keep an update you turn down. Backdrop will not ask about that version again, and Settings shows Install update until you install it or a newer release replaces it.
- Finish a waiting update by itself once Install unknown apps is allowed for Backdrop.
