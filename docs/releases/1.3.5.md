- **More economical backdrops.** Cinematic Home artwork avoids an extra fullscreen image copy and releases outgoing cached images after transitions.
- **Less artwork work at startup.** Home prepares a bounded first-row selection and loads additional app artwork as needed. Continue Watching preloads the selected item and one lookahead.
- **Quieter while another app is open.** Continue Watching refreshes, queued image work and clock updates pause while Home is hidden, then resume when you return.
- **Reliable offline artwork.** Interrupted image restoration keeps valid cached files, and returning can restore selected programme artwork even if the TV provider is temporarily unavailable.
- **Clock settings take effect immediately.** Switching between minute and second formats updates the existing clock timer correctly.

This release updates the current Flutter launcher. Native Android Home remains an experimental source prototype; its benchmark memory figures do not describe the released launcher APK.
